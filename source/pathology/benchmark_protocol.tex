\subsection{Benchmark Protocol}
\label{sec:benchmark}

To compare practitioners' intuitions against empirical outcomes, we fine-tuned a ResNet-50~\cite{he2016} pretrained on each of the three candidate source datasets on the same target tasks used in the case studies.

\paragraph{CS-tissue.} For each experiment, we sampled 250 patches per class from NCT-CRC-HE-100K~\cite{kather2019} for training and validation (80/20 stratified split), and used CRC-VAL-HE-7K with 250 patches per class held out as the test set (4,930 patches). Both the training sample and the test hold-out were controlled by a single data seed. Patient disjointness between training and test is guaranteed by construction, as the two sets originate from different institutions (NCT/UMM and TCGA, respectively). The model was trained with multi-class cross-entropy loss on nine tissue classes.

\paragraph{CS-xray.} We combined the official CheXpert~\cite{irvin2019} validation and test sets and retained only images with at least one positive label among the eight pathologies that had at least 100 positive examples (834 images, 662 patients). For each data seed, we performed a patient-level split: patients were assigned to training until approximately 250 images were accumulated (80/20 train/validation), with the remaining patients forming the test set. This guarantees that no patient appears in both training and test. The model was trained with binary cross-entropy loss on the eight pathology labels (multi-label).

\paragraph{Two-phase pipeline.} Both case studies shared the same fine-tuning pipeline. In the first phase, we searched for hyperparameters using Bayesian optimisation (Optuna~\cite{akiba2019}, 60 trials) over five data seeds; the configuration with the highest mean validation macro AUC across seeds was selected. In the second phase, we trained models with the selected hyperparameters on five held-out data seeds and evaluated them on the corresponding test sets. Crucially, the search and evaluation seeds were fully disjoint (0--4 vs.\ 5--9), so that the hyperparameters were never selected on the same data used to report final results. For CS-tissue we report balanced accuracy, macro-averaged F1, and macro-averaged AUC; for CS-xray we report macro-averaged AUC and per-pathology AUC. All metrics are given as mean and standard deviation across the five evaluation seeds. The full list of searched and fixed hyperparameters is provided in Appendix~\ref{app:hparams}.
