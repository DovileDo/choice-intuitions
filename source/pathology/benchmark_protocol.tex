\subsection{Benchmark Protocol}
\label{sec:benchmark}

To compare practitioners' intuitions against empirical outcomes, we fine-tuned a ResNet-50~\cite{he2016} pretrained on each of the three candidate source datasets on the same target tasks used in the case studies. We describe the protocol for the tissue classification task (CS-tissue) below; the chest radiograph task (CS-xray) follows an analogous setup.

For each experiment, we sampled 250 patches per class from NCT-CRC-HE-100K~\cite{kather2019} for training and validation (80/20 stratified split), and used CRC-VAL-HE-7K with 250 patches per class held out as the test set (4,930 patches). Both the training sample and the test hold-out were controlled by a single data seed. Patient disjointness between training and test is guaranteed by construction, as the two sets originate from different institutions (NCT/UMM and TCGA, respectively).

The fine-tuning pipeline consisted of two phases. In the first phase, we searched for hyperparameters using Bayesian optimisation (Optuna~\cite{akiba2019}, 60 trials) over five data seeds; the configuration with the highest mean validation macro AUC across seeds was selected. In the second phase, we trained models with the selected hyperparameters on five held-out data seeds and evaluated them on the corresponding test sets. Crucially, the search and evaluation seeds were fully disjoint (0--4 vs.\ 5--9), so that the hyperparameters were never selected on the same data used to report final results. We report the mean and standard deviation of balanced accuracy, macro-averaged F1, and macro-averaged AUC across the five evaluation seeds. The full list of searched and fixed hyperparameters is provided in Appendix~\ref{app:hparams}.
